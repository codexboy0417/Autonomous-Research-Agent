[B] TEXT BLUR & CANVAS RESOLUTION FIX
--------------------------------------
1. Problem: Canvas low-resolution backing store par CSS ke through stretch ho raha tha, 
   jiski wajah se saara text aur graphics blur/fuzzy dikh rahe the.
2. Root Cause: Windows OS ka display scaling (125%-150%) aur standard canvas resolution mismatch.
3. Solution Applied:
   - Canvas internal backing store device ke physical pixel ratio (`devicePixelRatio >= 2.0`) 
     ke barabar set kiya gaya: `canvas.width = clientWidth * dpr`.
   - Map rendering ko integer 2x retro pixel scaling par lock kiya gaya (`imageSmoothingEnabled = false`).
   - Native DOM fonts me `Inter` aur `JetBrains Mono` define karke `-webkit-font-smoothing: antialiased` 
     lagaya gaya, jisse text 100% razor-sharp render hone laga.

[C] DESK SEATING & KEYBOARD OVERLAP (CHOPPED HEADS FIX)
-------------------------------------------------------
1. Problem: Desks par baithe characters ke chehre par keyboard tile aa rahi thi aur unke 
   gale cut gaye the (Screenshot: media_1791144530358.png).
2. Root Cause: `furniture-above` layer characters ke baad draw ho rahi thi, aur PC desks 
   par character facing direction `down` tha jabki monitor upar (North) tha.
3. Solution Applied:
   - Saari tile layers (`furniture-above` samet) characters se PEHLE draw hoti hain.
   - PC workstations (Jim, Kelly, Dwight) par seating facing direction `up` (monitor ki taraf) 
     set kiya gaya.
   - Leg cropping (`crop = 4px`) ke sath characters naturally chair par baith kar monitor 
     par type karte hain.
   - Michael CEO cabin me `down` face karke table ke peeche upright baithta hai.

[D] ANTI-COLLISION SPEECH BUBBLES FIX
-------------------------------------
1. Problem: Do paas-paas baithe characters ke speech bubbles ek doosre ke upar overlap ho rahe the.
2. Solution Applied:
   - Engine me `Anti-Collision Overlap Resolver` add kiya gaya.
   - Sabhi active bubbles ke screen coordinates aur dimensions calculate hote hain.
   - Agar do bubbles aapas me takraate hain, to ek bubble doosre ke theek upar vertically stack 
     ho jaata hai (`by = other.by - bubbleH - 4px`).

4. HOW THINGS WORK UNDER THE HOOD (TECHNICAL ARCHITECTURE)
================================================================================

[1] DECORATOR-DRIVEN BACKEND ARCHITECTURE (decorators.py & agents.py):
-----------------------------------------------------------------------
- `@boss(name="The_Boss", role="Executive Research Director", desk_id=0)`:
  Ye decorator function ko executive director declare karta hai. Jab query aati hai, ye 
  query ko academic aur market sub-tasks me decompose karta hai aur final report synthesize karta hai.
- `@employee(name="...", role="...", desk_id=..., collection="...")`:
  Ye decorator employee functions ko bind karta hai:
  * Dr_Arxiv (Jim Halpert): `academic_papers` collection se research retrieve karta hai.
  * Data_Dex (Kelly Kapoor): `market_intelligence` collection se commercial metrics nikaalti hai.
  * Vera_Audit (Dwight Schrute): Evidence ka adversarial fact-checking audit karta hai.

[2] LOCAL VECTOR RAG ENGINE (rag_engine.py):
---------------------------------------------
- FAISS `IndexFlatIP` (CPU Inner Product / Cosine Similarity):
  Har collection memory me indexed vector space rakhti hai.
- DenseEmbeddingModel:
  128-dimensional dense projection jo query aur documents ko fast embedding me convert karta hai.
- CrossEncoderReranker:
  Top candidate chunks ko deep semantic relevance ke basis par bi-directional re-score karta hai.

[3] REAL-TIME PUB/SUB EVENT STREAM (server.py & decorators.py):
---------------------------------------------------------------
- `OfficeEventBus`: Async in-memory pub/sub queue.
- Har agent ka action (`status="thinking"`, `"walking"`, `"retrieving"`, `"done"`) 
  ek `AgentEvent` object banta hai.
- FastAPI ka endpoint `/api/office/events` is event stream ko Server-Sent Events (SSE) 
  ke format me browser ke `EventSource` ko real-time me bhejta hai.

[4] 2D CANVAS GAME ENGINE & PATHFINDING (office-canvas.js):
----------------------------------------------------------
- Map Collision Grid:
  `office-map.json` ki collision layer ko 34x22 boolean grid me parse kiya jaata hai.
- Breadth-First Search (BFS) Pathfinding:
  Jab koi agent point A se point B jaata hai, BFS algorithm corridors ke through shortest 
  walkable path find karta hai. Koi bhi character walls ya furniture ke aar-paar clip nahi karta.
- Walking Speed:
  48 pixels/second speed par smooth delta-time movement chalti hai.
- High-DPI Drawing Pipeline:
  Device pixel density (`dpr >= 2`) par canvas scale hota hai. Tile layers pehle draw hoti hain, 
  characters unke upar draw hote hain, aur anti-collision speech bubbles sabse upar float karte hain.
